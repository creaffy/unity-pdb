# unity-pdb
UnityPlayer.dll PDB downloader <br/>

> Bases on [ero-qt/Unity-PDB-Downloader](https://github.com/ero-qt/Unity-PDB-Downloader) but unlike it, supports Unity 6.x.

### Usage
```
> python unity-pdb.py path/to/UnityPlayer.dll
```
The downloaded PDB file will be placed in the same directory as the DLL.
